# Nexus Harness desktop releases

Download the latest Windows x64 installer from [Releases](https://github.com/kikopedia/NexusHarness-Releases/releases/latest).

In Nexus Harness v0.1.2, open **Settings > General > Check for updates** to download a newer installer. From v0.1.3 onward, Nexus also checks on startup and every four hours, and shows **Update available** above the profile in the sidebar.

Download and run the installer after finishing your work. Updates are installed manually.
